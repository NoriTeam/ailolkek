# Устройство проекта

Расчёты находятся в `math.js`, формы и конвертеры — в `catalog.js`. Интерфейс собирает `app.js`. Модули `universe.js`, `events.js` и `action-games.js` отвечают за персонажей, экономику и игры. `enhancements.js` содержит обучение, голосовой ввод и генератор аватарок; игры стакана вынесены в `beer-games.js`.

## Материал

`source/aori/` — исходники SDF-ядра, шейдера и рендерера Aori Surface. Их JS-версии лежат в `vendor/aori/`. Адаптер `surface.js` связывает DOM с одним WebGL-контекстом. Рендерер отсекает невидимые панели и останавливается, когда реакция закончилась. DOM измеряется при изменении раскладки. При отсутствии WebGL остаётся CSS-оформление.

SVG-иконки загружены из [Lucide](https://lucide.dev/). Исходники и лицензия: `assets/lucide/`. На главном экране последние расчёты заменили декоративные формы. При выборе структуры учитывались [наблюдения NN/g о типовых AI-прототипах](https://www.nngroup.com/articles/ai-prototyping/).

## Сервер

`server/api.js` работает в Worker с D1. `server/worker.js` обслуживает API и статические файлы. Скрипт `server/build-host.mjs` собирает публикацию в соседнем каталоге `calculate-online-host`. SQL-миграции применяются по порядку. У D1 есть [бесплатный тариф для небольших проектов](https://developers.cloudflare.com/d1/reference/faq/).

Аккаунты используют bcrypt с work factor 12; исходник bcryptjs и BSD-лицензия находятся в `vendor/bcryptjs/`. В базе хранится хеш случайного токена сессии. Сам токен приходит в HttpOnly cookie; в production добавляется Secure. Код восстановления хранится как SHA-256-хеш и меняется после использования. Смена пароля отзывает предыдущие сессии. На вход, регистрацию, публикации и выдачу наград действуют ограничения частоты.

Сообщения доступны только двум друзьям. Клиент не определяет свой user ID: сервер получает его из сессии. Кошельки обновляются транзакциями, повторные награды блокирует уникальная запись журнала. Ответы в клановой войне проверяет сервер. Официальные клубы имеют бот-состав; пользовательские кланы также появляются в списке соперников.

Изображения уменьшаются на клиенте и сохраняются в D1. Принимаются JPEG, PNG и WebP, до 500 КБ после обработки, максимум 40 файлов на аккаунт. SVG-загрузки запрещены. Опубликованные изображения доступны по URL.

Локальный сервер использует Node SQLite с тем же API. Отладочный вход существует только на loopback в локальном сервере и не попадает в Worker. Production игнорирует присланный клиентом заголовок user ID.

## Языки и кеш

`locale.js` переключает интерфейс и сохраняет выбор языка. Английские строки лежат в `locale-en.json`; перевод выполняется на устройстве, внешнего запроса к переводчику нет. Значения форм и сообщения пользователей не переводятся.

Service worker кеширует приложение и шрифты. Запросы API в кеш не попадают. Локальная история, игровые сохранения и сетевые данные независимы.

## Численные ограничения

В расчётах используется JavaScript Number. Точность в настройках меняет отображение. Производная считается центральной разностью, интеграл — методом Симпсона. Эти приближения рассчитаны на гладкие функции. Тесты покрывают парсер, формы, конвертации, награды, аккаунты, переписку, изображения и клановые бои.
