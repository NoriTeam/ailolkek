# Устройство Aori Calculate

Приложение целиком работает в браузере. Один и тот же набор статических файлов используется локально, на GitHub Pages и в офлайн-кеше.

| Файл              | Назначение                                                                        |
| ----------------- | --------------------------------------------------------------------------------- |
| `math.js`         | Токенизация, рекурсивный разбор выражений, функции и форматирование               |
| `catalog.js`      | 101 расчётная форма, 34 конвертации, статьи и основной каталог функций            |
| `app.js`          | Экран калькулятора, формы, локальная лента, история, профиль, графики и настройки |
| `universe.js`     | Валюта, персонажи, сюжет, награды, магазин, игры, музыкальный синтез и эффекты    |
| `style.css`       | Базовый интерфейс и адаптивная компоновка                                         |
| `universe.css`    | Клуб, магазин, новелла, реклама и игровые эффекты                                 |
| `events.js`       | Ивенты, пошаговый бой, RPG-экипировка и три боевых пропуска                       |
| `action-games.js` | Canvas-движок гонок и арены с рейкастингом                                        |
| `sw.js`           | Обновление оболочки по сети и возврат кеша без соединения                         |
| `server.js`       | Локальный статический сервер без сторонних пакетов                                |
| `tests/`          | Расчётные проверки и проверки переходов локальной экономики                       |

## Вычисления

Парсер идёт от выражения к терму, унарному оператору, степени и первичному значению. Возведение в степень правоассоциативно: `2^3^2 = 512`. Унарный минус имеет обычный математический приоритет: `-2^2 = -4`. Пользовательская строка не становится исполняемым JavaScript.

Каждый инструмент содержит поля, начальные значения, текст формулы и функцию расчёта. Конвертеры хранят прямое и обратное преобразования; температурные шкалы учитывают смещение нуля.

## Состояние

Ключ `aori-calculate-v1` хранит один JSON-документ. История ограничена 500 записями, журнал валюты — 150 событиями, уведомления — 80. Импорт резервной копии проверяет структуру, допустимые режимы и числовые диапазоны. Пользовательский текст экранируется перед выводом.

Даты серий и наград считаются в локальном времени посетителя. Награда за вход, задание и этап сезона имеет отдельную отметку получения. За обычные вычисления выдаётся не более 50 Σ в день. Витрина допускает до шести награждаемых просмотров в сутки; просмотр засчитывается после восьми секунд в активной вкладке. На серверную защиту от изменения локального состояния проект не претендует.

## Публикации и сюжет

Публикация содержит выражение и его вычисленный результат. Истории скрываются через 24 часа. Стартовые авторы явно представлены как редакционные коллекции. Ссылки передают только выражение через параметр `expression`.

Новелла состоит из восьми глав. Верный ответ открывает выбор действия, выбор сохраняет прогресс и выдаёт награду. Финальная развилка предлагает три завершения. Пройденные главы остаются доступны для чтения.

## Звук и доступность

Музыка и короткие звуки синтезируются осцилляторами Web Audio. Автовоспроизведения после загрузки нет. При скрытии вкладки аудиоконтекст приостанавливается. Голос использует системный SpeechSynthesis; русский голос зависит от устройства.

Клавиатурный ввод, семантические кнопки, подписи полей, модальные `dialog`, `aria-live` для результата и уведомлений. Эффекты учитывают `prefers-reduced-motion` и собственную настройку анимации.

## Ивенты и режимы действия

Три ивента используют личный 14-дневный цикл. Пройденный этап открывает следующий; первая победа выдаёт жетоны, повторная обновляет рекорд. Шесть артефактов меняют характеристики RPG-персонажа. Боевая система хранит здоровье, энергию, защиту, ослабление и перезарядку навыка. Незавершённый пошаговый бой переживает перезагрузку страницы.

Три боевых пропуска имеют отдельные счётчики прогресса и отметки получения каждой награды. Основная и расширенная дорожки проверяются отдельно. Расширенная дорожка расходует 120 внутренних Σ; реальных платежей нет.

Арена строит вид от первого лица рейкастингом по двумерной карте. Буфер глубины скрывает числовых ботов за стенами. Выстрел проверяет угол прицеливания, расстояние и прямую видимость. Урон засчитывается только цели с ответом на текущее выражение. Боты приближаются и атакуют, а в королевской битве зона постепенно сужается. Это локальная игра с ботами, без сетевого матчмейкинга.

Гонки используют перспективную проекцию трассы, столкновения, три полосы и ворота с числовыми вариантами ответа. Награда выдаётся после завершённой попытки. Закрытие игрового окна останавливает цикл анимации и снимает обработчики управления. Сворачивание вкладки приостанавливает игровое время.
